# MVP 05 — Wygląd: glassmorphism, motywy, ekran powitalny

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (tryb z CLAUDE.md od fazy 6). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplikacja w stylu glassmorphism z motywem jasnym i ciemnym (przełącznik, domyślnie według systemu) oraz ekranem powitalnym „Spokojny nastrój” (spec §6.1, §6.9, §6.2: nazwa aplikacji w pasku).

**Architecture:** Kolory wyłącznie jako tokeny CSS w `src/styles/globals.css` (`:root` i `.dark`, spójne z shadcn-vue), szkło jako narzędzia Tailwind (`@utility`) na tle z rozmytych plam (`AppBackdrop.vue`). Motyw trzyma store Pinia `src/stores/theme.ts` (czysta funkcja `resolveTheme` + klasa `.dark` na `<html>`); krótki skrypt w `index.html` ustawia klasę przed pierwszym malowaniem. Ekran powitalny w `src/app/splash/` (konfiguracja tekstów, composable z logiką czasu i pomijania, komponent z animacją CSS) jest nakładką nad aplikacją, więc dane ładują się równolegle.

**Tech Stack:** Vue 3, Tailwind CSS v4 (`@utility`, `@custom-variant dark`), VueUse (`usePreferredDark`, `usePreferredReducedMotion`, `useStorage`: API sprawdzić w Context7), Vue Flow (zmienne CSS motywu: sprawdzić w Context7), Vitest, Playwright.

**Spec:** `docs/specs/2026-11-04-mvp-design.md` (§6.1, §6.2, §6.9, §7 e2e: „start → ekran powitalny → drzewo”, „przełączenie motywu”)
