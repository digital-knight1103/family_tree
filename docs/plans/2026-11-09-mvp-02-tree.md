# MVP 02: Drzewo (prototyp układu, punkt kontrolny, wizualizacja)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Drzewo rodziny na płótnie Vue Flow z automatycznym układem elkjs, spełniające właściwości ze spec §6.4, z węzłami osób według §6.3, zaznaczaniem, minimapą, kontrolkami i „Wyśrodkuj na mnie”.

**Architecture:** Czysta logika w `src/domain/tree-layout/`: przydział pokoleń (`generations.ts`), budowa grafu osób i węzłów pomocniczych związków (`graph.ts`), układ elkjs w trybie layered z partycjami = pokolenia (`layout.ts`). Feature `src/features/tree/` zamienia wynik na węzły i krawędzie Vue Flow (krawędzie rysowane z punktów tras elkjs, bez przeliczania przez Vue Flow). Zaznaczenie żyje w osobnym store `src/stores/selection.ts`, bo w fazie 5 użyje go panel boczny.

**Tech Stack:** jak w planie 01, plus `elkjs` (`elkjs/lib/elk.bundled.js`, bez workera), `@vue-flow/core`, `@vue-flow/minimap`, `@vue-flow/controls`.

**Spec:** `docs/specs/2026-11-04-mvp-design.md` (§6.2, §6.3, §6.4, §7, §11 pkt 4)

## Review Focus

1. **Partner z innego pokolenia albo związek z własnym potomkiem** (dane to dopuszczają): przydział pokoleń musi się zakończyć i dać wynik, a drzewo się wyrenderować, zamiast zawiesić kartę. Test w Task 1.
2. **Dziecko z więcej niż dwojgiem rodziców** (dwoje biologicznych + adopcyjny, jak Marta w seed) **albo z rodzicami bez rekordu związku**: każda relacja rodzic–dziecko ma krawędź, nic nie znika. Test w Task 2.
3. **Osoba z dwoma związkami** (drugie małżeństwo): dzieci każdego związku wychodzą z węzła właściwego związku, nie z drugiego (anty-cel „dzieci podpięte nie do tej pary”). Test w Task 2 i Task 3.
4. **Zmiana danych w trakcie liczenia układu:** starszy wynik nie nadpisuje nowszego (wygrywa ostatnie żądanie). Test w Task 7.
5. **Duże drzewo (~300 osób):** układ liczy się w rozsądnym czasie (< 3 s w Node), bez zawieszenia. Test w Task 7.

Przypisanie dziecka: zbiór rodziców P. Jeśli w P jest para będąca związkiem (pierwszy związek po id), dziecko wisi pod tym związkiem, pozostali rodzice łączą się bezpośrednio.
